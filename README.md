# ifact plugins

The ifact plugin for Claude: design on an infinite canvas you share with AI agents.

- [`ifact/`](ifact): the ifact skill and the remote MCP server at `https://ifact.net/mcp`
- Claude Code: `/plugin marketplace add gpro-team/ifact-plugins`, then `/plugin install ifact@ifact`
- Claude (web, desktop, mobile): add ifact from the directory, or add the custom connector `https://ifact.net/mcp`

Docs: https://ifact.net/docs · Privacy: https://ifact.net/privacy · Support: support@ifact.net
